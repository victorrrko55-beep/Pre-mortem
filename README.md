# 주유수첩 — 자동차 주유 관리 앱

영수증 한 장으로 주유 기록과 연비를 관리하는 모바일 우선(mobile-first) 웹 앱입니다.
스마트폰 브라우저에서 열어 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 주요 기능

- **차량 설정 / 선택**: 처음 실행 시 차량을 등록하고, 여러 대의 차량을 등록해
  전환하며 기록을 분리 관리할 수 있습니다.
- **영수증 스캔 자동 입력**: 주유 후 영수증을 카메라로 찍으면(또는 앨범에서
  선택) 브라우저 안에서 OCR(Tesseract.js, 한국어+영어)로 인식하여
  **날짜 · 주유소명 · 주소 · 유종(일반/고급/경유/LPG) · 주유량 · 주유금액 ·
  단가 · 결제 카드**를 자동으로 채웁니다. 인식 결과는 저장 전에 확인·수정할
  수 있습니다.
- **연비 자동 계산**: 이동 거리와 총 주행거리(계기판 누적)는 직접 입력하며,
  이동 거리 ÷ 주유량으로 연비(km/L)가 계산되어 표시됩니다. 총 주행거리를
  입력하면 직전 기록과의 차이로 이동 거리를 자동 제안합니다.
- **월별 트렌드**: 주유금액, 주유량, 이동거리, 월 평균 연비를 월별 차트로
  확인할 수 있습니다.

## 사용 흐름

1. 첫 실행 → 차량 등록 (이름, 번호, 기본 유종)
2. 주유 후 → `주유 입력` 탭에서 영수증 촬영 → 자동 입력 확인 → 이동 거리/총
   주행거리 입력 → 저장
3. `홈` 탭에서 월별 기록과 요약(이번 달 금액·주유량, 평균 연비, 총 주행거리) 확인
4. `트렌드` 탭에서 월별 추이 확인

## 데이터와 개인정보

- 모든 데이터는 브라우저 `localStorage`에만 저장됩니다(서버/로그인 없음).
- 영수증 이미지도 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.
- 단, OCR 언어 데이터(수 MB)를 최초 1회 CDN에서 내려받으므로 첫 스캔 시
  네트워크 연결이 필요합니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드
npm run lint     # oxlint
```

## 스택

- React 19 + TypeScript + Vite
- Tailwind CSS 4
- Zustand (localStorage persist)
- Tesseract.js (브라우저 내 OCR)
